# ESP32 PC Controller

[English](README.md) | Русский

Контроллер удалённого управления питанием ПК на базе ESP32-C3 Super Mini с веб-интерфейсом, HTTP API, порталом настройки Wi-Fi и отслеживанием состояния компьютера.

<img width="908" height="569" alt="1789894904" src="https://github.com/user-attachments/assets/171e0801-e195-4d86-8a75-3e0893b5e4fe" />

## Возможности

* Удалённое включение ПК
* Запрос штатного завершения работы
* Принудительное выключение ПК
* Проверка текущего состояния ПК
* Настройка Wi-Fi через веб-интерфейс
* Светодиодная индикация состояния подключения
* Портал настройки с автоматическим открытием (Captive Portal)

## Требования

### Оборудование

Вам понадобятся:

* ESP32-C3 Super Mini
* Провод Dupont «мама — папа»
* Кабель USB Type-C

### Библиотеки Arduino IDE

Установите следующую библиотеку:

* **ESPping**, авторы: *dvarrel, Daniele Colanardi, Marian Craciunescu*

## Первоначальная настройка

### 1. Параметры точки доступа

Название сети и пароль для первоначальной настройки можно изменить в прошивке:

```cpp
// Wi-Fi AP Configuration
#define AP_SSID "ESP32-PC-Controller"
#define AP_PASSWORD "password123"
```

В целях безопасности рекомендуется изменить пароль по умолчанию перед загрузкой прошивки.

### 2. Подключение к сети настройки

После первого запуска ESP32 создаст собственную сеть Wi-Fi:

```text
SSID: ESP32-PC-Controller
Password: password123
```

Подключите телефон или компьютер к этой сети.

### 3. Открытие страницы настроек

Если портал настройки не открылся автоматически, перейдите по адресу [http://192.168.4.1](http://192.168.4.1).

<img width="995" height="677" alt="1789894945" src="https://github.com/user-attachments/assets/539e20fd-a25b-4edf-aa8f-656294816da3" />

Укажите следующие данные:

* SSID основной сети Wi-Fi
* Пароль основной сети Wi-Fi
* Локальный IP-адрес управляемого ПК

ESP32 использует IP-адрес ПК для проверки его доступности с помощью ICMP ping-запросов.

Рекомендуется назначить ПК статический IP-адрес или настроить резервирование адреса DHCP на роутере.

## Разрешение ICMP Ping

На ПК должны быть разрешены входящие эхо-запросы ICMPv4.

### Windows

Запустите PowerShell от имени администратора:

```powershell
New-NetFirewallRule -Name "Allow ICMPv4" -DisplayName "Allow ICMPv4" -Direction Inbound -Action Allow -Protocol ICMPv4
```

### Linux с iptables

Выполните:

```bash
sudo iptables -A INPUT -p icmp --icmp-type echo-request -j ACCEPT
```

В зависимости от дистрибутива Linux может потребоваться сохранить правила межсетевого экрана, чтобы они действовали после перезагрузки.

Для Debian или Ubuntu с установленным `iptables-persistent`:

```bash
sudo netfilter-persistent save
```

## Использование

После подключения ESP32 к сети Wi-Fi используйте её локальный IP-адрес для доступа к API.

Замените `<ESP32_IP>` на IP-адрес ESP32, назначенный роутером.

### Включение ПК

```http
POST http://<ESP32_IP>/on
```

Пример с использованием `curl`:

```bash
curl -X POST http://<ESP32_IP>/on
```

Этот запрос имитирует обычное нажатие кнопки питания.

### Выключение ПК

```http
POST http://<ESP32_IP>/off
```

Пример:

```bash
curl -X POST http://<ESP32_IP>/off
```

Этот запрос имитирует обычное нажатие кнопки питания.

Дальнейшее поведение операционной системы зависит от настроек действия кнопки питания на ПК.

### Принудительное выключение ПК

```http
POST http://<ESP32_IP>/forceoff
```

Пример:

```bash
curl -X POST http://<ESP32_IP>/forceoff
```

Этот запрос удерживает кнопку питания достаточно долго для принудительного выключения ПК.

> [!CAUTION]
> Принудительное выключение может привести к потере данных или повреждению файловой системы. Используйте его только тогда, когда операционная система не отвечает.

### Получение состояния ПК

```http
GET http://<ESP32_IP>/status
```

Пример:

```bash
curl http://<ESP32_IP>/status
```

Пример ответа в формате JSON:

```json
{
  "state": "on",
  "stateText": "PC is On",
  "value": 1
}
```

Конкретные значения зависят от определений состояний в прошивке.

### Очистка сохранённых настроек

```http
GET http://<ESP32_IP>/clear_config
```

Пример:

```bash
curl http://<ESP32_IP>/clear_config
```

Этот запрос удаляет сохранённые настройки Wi-Fi и ПК.

После очистки настроек ESP32 вернётся в режим точки доступа для настройки.

## Справочник API

| Метод | Путь | Описание |
| ----- | ---- | -------- |
| `POST` | `/on` | Нажать кнопку питания для включения ПК |
| `POST` | `/off` | Нажать кнопку питания для выключения ПК |
| `POST` | `/forceoff` | Удерживать кнопку питания для принудительного выключения ПК |
| `GET` | `/status` | Получить текущее состояние ПК в формате JSON |
| `GET` | `/clear_config` | Удалить сохранённые настройки |
| `GET` | `/settings` | Открыть страницу настроек Wi-Fi и ПК |

## Светодиодная индикация

Встроенный светодиод, подключённый к `GPIO8`, показывает текущее состояние сети.

| Поведение светодиода | Состояние |
| ------------------- | --------- |
| Горит постоянно | Wi-Fi не подключён или активна точка доступа для настройки |
| Меняет состояние каждую секунду | Wi-Fi подключён, ПК отвечает на ping |
| Пять быстрых вспышек, затем секунда без свечения | Wi-Fi подключён, но ПК не отвечает на ping |
| Быстро мигает | Выполняется подключение к указанной сети Wi-Fi |

Если ESP32 не удаётся подключиться к указанной сети Wi-Fi, она продолжает попытки в течение трёх минут.

Через три минуты снова запускается точка доступа для настройки:

```text
ESP32-PC-Controller
```

После этого можно снова подключиться к сети настройки и изменить параметры по адресу:

```text
http://192.168.4.1/settings
```

## Безопасность

API не предусматривает аутентификацию, если она не реализована отдельно в прошивке.

Используйте устройство только в доверенной локальной сети. Не открывайте ESP32 прямой доступ из интернета без добавления аутентификации, контроля доступа и шифрования.

Также следует изменить пароль точки доступа по умолчанию:

```cpp
#define AP_PASSWORD "password123"
```

## Устранение неполадок

### ESP32 не определяет, включён ли ПК

Проверьте, что:

* IP-адрес ПК указан правильно
* Для ПК настроен статический IP-адрес или резервирование DHCP
* Межсетевой экран разрешает эхо-запросы ICMPv4
* ESP32 и ПК подключены к одной локальной сети

### ESP32 не подключается к Wi-Fi

Проверьте указанные SSID и пароль.

ESP32 будет пытаться подключиться в течение трёх минут. Если подключение не удастся, точка доступа для настройки включится автоматически.

### Управление кнопкой питания через API не работает

Проверьте:

* Расположение контактов разъёма передней панели материнской платы
* Соединение между `POWER+` и `GPIO2`
* Настройки GPIO в прошивке
